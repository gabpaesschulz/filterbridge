# Short Descriptions

## One-liner

> Schema-first filter library for React admin screens — declare once, reuse as React state, URL params, and backend DTOs.

## One paragraph

FilterBridge is a small TypeScript library that solves a repetitive problem in React admin dashboards: the same filter logic being written separately for UI state, URL search params, and backend query DTOs. You define filters once as a typed schema and derive consistent parsing, serialization, and DTO generation from that single definition. It ships as five focused npm packages, with adapters for browser URL sync, TanStack Table, and Next.js App Router.
