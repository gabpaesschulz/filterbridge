# FilterBridge v0.1.0

Initial experimental release.

---

## Highlights

- **Schema-first API** — declare filters once with `defineFilters()` and derive parsing, serialization, and backend DTOs from a single definition
- **6 filter types** — `text`, `select`, `multiSelect`, `boolean`, `dateRange`, `numberRange`
- **Full TypeScript inference** — literal union types for `select` and `multiSelect` inferred from schema
- **Zero framework dependency in core** — `@filterbridge/core` has no React dependency
- **299 automated tests**

## Install

```bash
npm install @filterbridge/core
npm install @filterbridge/react      # React hook
npm install @filterbridge/browser    # browser URL sync
npm install @filterbridge/tanstack   # TanStack Table adapter
npm install @filterbridge/next       # Next.js App Router adapter
```

---

## Quick example

```ts
import { defineFilters, text, multiSelect, parseFilters, toQueryDto } from '@filterbridge/core'

const filters = defineFilters({
  search: text(),
  status: multiSelect(['pending', 'paid', 'failed']),
})

const state = parseFilters(filters, { search: 'acme', status: 'paid,failed' })
const dto = toQueryDto(filters, state)
// { search: 'acme', status: ['paid', 'failed'] }
```
